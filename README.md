# GAS LEAKAGE MONITOR

## PROJECT DESCRIPTION
This project is an IoT-based gas leakage monitoring system developed using ESP32.
It uses a gas sensor to detect gas concentration and provides an alert using an LED and buzzer when leakage is detected.

## COMPONENTS USED
- ESP32 Microcontroller
- Gas Sensor (MQ Sensor)
- LED
- Buzzer
- Breadboard
- Jumper Wires

## SOFTWARE USED
- Arduino IDE
- Wokwi Simulation

## WORKING PRINCIPLE
The gas sensor continuously measures the gas level from the environment.
The ESP32 reads the analog sensor value and compares it with a predefined threshold.
If the gas level exceeds the limit, the LED and buzzer are activated as an alert.
If the gas level is normal, the system remains in a safe state.

## FEATURES
- Real-time gas level monitoring
- Gas leakage detection
- Audio and visual alert system
- Wi-Fi enabled ESP32 system
- Embedded safety application


## APPLICATIONS
- Gas safety monitoring
- Smart home safety systems
- Industrial safety systems
- IoT-based monitoring applications
